# Founder progress publication

The founder showcase receives progress through a one-way, manually reviewed snapshot. It is not connected to private manuscripts, governed write services, credentials, or authority records.

## Publication states

1. **Draft** — generated privately and not suitable for public use.
2. **Reviewed** — checked by a human for accuracy, scope, and disclosure risk.
3. **Published** — merged into this public repository after automated validation and human approval.

MOMMA may prepare or critique a draft. MOMMA cannot approve or publish it. A passing automated check establishes structural and disclosure-policy compliance only; it does not establish truth, ownership, canon, or corporate approval.

## Required release path

1. Generate a new snapshot from the private repository.
2. Review every public sentence. Remove source text, manuscript content, private evidence, credentials, and operational secrets.
3. Set the source commit and generation date.
4. Record the human release governor and approval time. This is attribution, not a cryptographic signature.
5. Open a pull request changing the snapshot and any required presentation text.
6. Require the founder showcase validation workflow to pass.
7. Merge the pull request. GitHub history becomes the publication evidence.

Never automate the final merge from MOMMA output. Creator-controlled claims must remain reserved until the controlling creator rules on them.
